Privacy

What The Nex keeps on your computer, what it sends to its sign-in and sync service, and what it never does. No cookies, no analytics, no ads. Threat detection runs on your device.

Stored on this device (browser storage)

thenex.session
Supabase access and refresh token, expiry time, your user id and email. Removed when you sign out. Your password is never stored.
thenex.device.<user>
A random device id and the device name, one record per account.
thenex.theme
Dark, light or match system.
thenex.appearance
Wallpaper choice (including a URL if you pasted one), background dim, card blur and card opacity.
aegismesh.form, .profile, .camera, .signtests
AegisMesh console settings and sign-test results. Camera frames are processed on this device and are never recorded or sent anywhere.

Stored in the app data folder (local only)

Settings (settings.json), wallpaper images, the event log (events.jsonl, with file paths and hashes), quarantined files, the always-allowed list, the never-scan list, and the last scan report. None of this is uploaded.

What it looks at on this computer

  • All the time: new and changed files in the Downloads and Desktop folders of every account and in temporary folders (on a Mac, only the shared /tmp), and the program file, path and command line of each running program. It puts hidden decoy files in Desktop and Documents.
  • Quick and scheduled scans: everyone's Downloads and Desktop.
  • Full scan, which you start: every account's files and the places software is installed; on Windows, the whole system drive.
  • Startup list, which you open: what starts with the computer.
  • Never scan (Settings, Exceptions): folders and files you list there are not opened, moved or deleted, and get no decoys. Changing the list needs an administrator and is written to the event log. A running program's path and command line are still looked at, and if the ransomware decoys point to a program in such a place, its signature is read and it can still be stopped. A file you drop on the window to check is checked wherever it is.

Sent to Supabase (hosted service)

  • Account (Supabase Auth): your email, a hash of your password, and authentication logs that include your IP address and user agent.
  • Devices table: device id, device name, platform, app version and a status summary: online, dry run, number of engines on, and counts of threats, quarantined files and canaries. Updated every 60 seconds while the app is running and you are signed in. No file paths or event details are included.
  • Device commands: the command you send to a device (quick scan or canary check), its status and a small result summary.
  • Network metadata: while you are signed in the app contacts Supabase every 15 seconds and every 60 seconds, which reveals your IP address and activity times to Supabase.

Profile photo (Gravatar)

To show your profile photo, the app asks Gravatar (gravatar.com, run by Automattic) for the picture linked to a SHA-256 hash of your email. Gravatar sees that hash and your IP address. If there is no picture, your initials are shown instead.

Wallpaper downloads

If you paste a wallpaper URL, that page's host is contacted, then the image host it points to (which may differ), following redirects; the image is stored locally. Those hosts see your IP address.

Device rows and command history stay on Supabase after sign-out or uninstall until you remove them from the Devices page (or the project owner deletes the account). In-app account deletion is not available yet.
