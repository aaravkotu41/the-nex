## What's new in 0.4.1

**Far fewer false alarms on a developer's Mac**
- Compiler object files (`.o`) are no longer treated as programs. They are build leftovers that
  cannot run, but the AI flagged them: a Full Scan of one developer's Mac reported 12,451
  findings, and 12,408 of them were object files. In a watched folder with Dry Run off they
  could have been quarantined in the middle of a build.
- Measured on the same Unity editor folder (197,031 files): 1,254 findings before, 28 now. The
  28 left are vendor libraries the AI still gets wrong. A Full Scan lists them but never moves
  them.

**Dashboard**
- The "Threats, last 7 days" chart now counts every event. It used to stop at the newest 1,000,
  so a busy day showed "1,000" next to a Threats tile saying 12,830.
- Chart numbers have thousands separators, and quiet days stay visible next to a very busy one.
- The Activity page still lists only the newest 1,000 events, and now says so instead of showing
  that as the total.

Every build is tested on Windows and macOS runners: unit tests, a live end-to-end check, AI
false-positive gates on each runner's own programs, and a full install and uninstall.
