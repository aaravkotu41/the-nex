## What's new in 0.4.0

**Accounts and your devices**
- The dashboard now opens on a sign-in screen (email and password, or **Create account**).
  Protection keeps running whether or not anyone is signed in.
- New **Devices** page: see each computer signed in to your account, and start a Quick Scan or a
  canary check on one of them from another.
- While you are signed in, a small device summary (counts and on/off switches, never file
  paths) goes to Supabase. Settings → Privacy lists everything that leaves the device.

**Scans**
- New **Full Scan**: checks everywhere software can be installed or dropped. It only reports;
  it never moves, deletes or stops anything.
- On macOS, scans are run by the background service, so they no longer ask for an
  administrator password each time.
- A folder the system refuses to open is named in the result instead of being counted as clean.

**Known-malware list (new engine, idle for now)**
- The Nex can now check every new file and every newly started program against a list of known
  malware, and quarantine exact matches.
- **No list ships in this release**, so this engine does nothing yet and the dashboard says
  "no list installed". The other engines are not affected.

**Smarter on-device AI**
- New model that ignores signature blocks it cannot verify and is trained against common
  disguises. False alarms on real programs it had never seen fell from 0.82% to 0.46%.

**macOS**
- A menu-bar item (gyroscope icon) with Open, Quick Scan, Full Scan and shortcuts. Closing the
  window keeps The Nex running in the menu bar.
- The background service now runs from its own copy in a folder only administrators can change.

**AegisMesh**
- **My SOS triggers**: teach your own hand signs, expressions and movements (a wave, a circle,
  a swipe), and keep any number of tap rhythms.
- Camera picker, an allow-camera bar, and lighting and framing tips.
- 3D models of the ring, bracelet and clothing tag.

**New look**
- Redesigned dashboard with light and dark mode, your own wallpaper, and adjustable card blur
  and opacity.
- New gyroscope icon.

Every build is tested on Windows and macOS runners: unit tests, a live end-to-end check, AI
false-positive gates on each runner's own programs, and a full install and uninstall.
